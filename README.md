# Cumpleaños de Irene 🎉🃏

Web tipo baraja de UNO para el cumpleaños de Irene. Lista para subir a GitHub Pages.

## Cómo añadir tus fotos y memes

1. Mete tus fotos en la carpeta `images/` con estos nombres exactos:
   `foto1.jpg`, `foto2.jpg`, `foto3.jpg`, `foto4.jpg`, `foto5.jpg`, `foto6.jpg`
   (puedes usar `.png` si cambias también la extensión en el `index.html`, busca `src="images/...`).

2. Mete tus memes en la carpeta `memes/` con estos nombres:
   `meme1.jpg`, `meme2.jpg`, `meme3.jpg`, `meme4.jpg`

3. Si te sobran o faltan huecos, copia o borra los bloques `<figure class="photo-card">...</figure>`
   (fotos) o `<div class="meme-card">...</div>` (memes) dentro de `index.html`.

4. Si quieres añadir o cambiar los mensajes de la sección "Roba una carta", edita el array
   `CARTAS` al final del `index.html` (dentro de la etiqueta `<script>`).

## Subir a GitHub Pages

1. Crea un repositorio nuevo (puede ser público o privado con GitHub Pro).
2. Sube `index.html`, la carpeta `images/` y la carpeta `memes/`.
3. Ve a Settings → Pages → Source → selecciona la rama `main` y la carpeta `/root`.
4. En un par de minutos tendrás la URL tipo `https://tu-usuario.github.io/tu-repo/`.
